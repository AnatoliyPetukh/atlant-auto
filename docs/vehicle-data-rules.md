# Правила данных автомобилей ATLANT AUTO

## Mercedes: дата PartsLink

Решение владельца от 17.10.2026: для Mercedes-Benz поле PartsLink «Дата поставки» используется в этом workflow как дата производства автомобиля, в том числе в объявлении. Аналогичные названия поля: Delivery date, Date of delivery, Lieferdatum. Это явно заданное правило проекта, а не универсальное преобразование дат для всех марок.

Исходное поле и его значение сохраняются без изменения. Производная дата содержит label исходного поля и mapping_rule=mercedes_delivery_as_production. Правило применяется к Mercedes или проверенному шаблону mercedes-columns-ru; дата поставки других марок не становится датой производства. Невалидные и противоречащие даты требуют проверки. При отсутствии даты действуют существующие правила первой регистрации Arval с отдельной подписью.

## Формат аукционного поста Arval

Решение владельца от 17.10.2026: ставка Arval в рекламном посте отображается как нетто, без отдельной строки «НДС к вычету». Правило меняет представление неизвестной налоговой базы и не переписывает исходное tax_basis; явно указанное брутто не переименовывается в нетто без расчёта. Дата первой регистрации пишется с подписью перед датой, пробег отдельной строкой, топливо и коробка одной строкой. Регион «Центр — Долина Луары» в кратком тексте сокращается до «Центр». В пояснениях хранилища сохраняется ограничение: расчётный таймер не отслеживает продления автоматически, но отдельная строка об этом из подписи поста убрана по просьбе владельца.
