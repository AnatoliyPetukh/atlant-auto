# Переход на новый компьютер

В рабочей папке находятся два независимых проекта. Их нужно клонировать как
две соседние папки, а не копировать один репозиторий внутрь другого.

## Репозитории

1. Atlant Auto: `https://github.com/AnatoliyPetukh/atlant-auto`
2. CarPlaza.by: `https://github.com/AnatoliyPetukh/carplaza-by`

Основная ветка обоих проектов — `main`. Репозитории приватные, поэтому на новом
компьютере нужно войти в GitHub под аккаунтом с доступом к ним.

Рекомендуемая структура папок:

```text
Projects/
  atlant-auto/
  carplaza-by/
```

## Что установить

- Git или GitHub Desktop;
- Codex;
- Node.js и npm — для генераторов и тестов Atlant Auto;
- современный браузер для локальной проверки сайтов.

CarPlaza.by — статический сайт и не требует сборки.

## Клонирование

Через GitHub Desktop можно выбрать **File → Clone repository** и по очереди
клонировать оба репозитория. Через терминал:

```powershell
git clone https://github.com/AnatoliyPetukh/atlant-auto.git
git clone https://github.com/AnatoliyPetukh/carplaza-by.git
```

После клонирования Atlant Auto:

```powershell
cd atlant-auto
npm install
npm test
```

Локальный просмотр Atlant Auto запускается командой:

```powershell
.\serve.ps1
```

CarPlaza.by можно проверить, открыв `index.html` в браузере. Публикация сайта
выполняется GitHub Actions после отправки изменений в `main`; FTPS-данные
хранятся в GitHub Secrets и на новый компьютер не переносятся.

## Что Git не переносит

Следующие данные намеренно исключены из Atlant Auto:

- `_backups/` — локальный архив Tilda;
- `_drive_latest_cars/` — временно импортированные фотографии;
- `_publish-homepl/` — генерируемая папка публикации;
- `tmp/` — временные файлы;
- `node_modules/` — восстанавливается командой `npm install`;
- ZIP-архивы и исходные PDF/документы;
- `.codex/` и `.agents/` — локальное состояние инструментов;
- пароли, ключи, `.env` и FTP-реквизиты.

Если архив Tilda, исходные документы или импортированные фотографии ещё
нужны, перенесите их отдельно через защищённый накопитель или облачное
хранилище. Пароли лучше заново получить из менеджера паролей, а не копировать
в папку проекта.

## Проверка перед отключением старого компьютера

В каждой папке проекта выполните:

```powershell
git status --short --branch
git push origin main
```

Перед окончательным переходом должны выполняться условия:

- нужные изменения закоммичены и отправлены в GitHub;
- `git status` не показывает важных незакоммиченных файлов;
- локальные архивы, документы и фотографии либо скопированы отдельно, либо
  подтверждены как ненужные;
- на новом компьютере оба репозитория клонируются и открываются;
- `npm test` проходит в Atlant Auto;
- у аккаунта GitHub есть доступ к Actions и Secrets обоих проектов;
- известны доступы к home.pl, доменам, Google Search Console, Analytics и другим
  внешним сервисам, если они используются.

Не удаляйте данные со старого компьютера, пока эти проверки не завершены.
