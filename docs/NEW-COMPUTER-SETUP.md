# Переход на новый компьютер

Эта инструкция относится только к проекту Atlant Auto:
`https://github.com/AnatoliyPetukh/atlant-auto`.

Основная ветка проекта — `main`. Репозиторий приватный, поэтому на новом
компьютере нужно войти в GitHub под аккаунтом с доступом к нему.

## Что установить

- Git или GitHub Desktop;
- Codex;
- Node.js и npm — для генераторов и тестов;
- современный браузер для локальной проверки сайта.

## Клонирование

Через GitHub Desktop выберите **File → Clone repository** и клонируйте
`AnatoliyPetukh/atlant-auto`. Через терминал:

```powershell
git clone https://github.com/AnatoliyPetukh/atlant-auto.git
cd atlant-auto
npm install
npm test
```

Локальный просмотр запускается командой:

```powershell
.\serve.ps1
```

Публикация на home.pl выполняется командой:

```powershell
.\publish-homepl.ps1
```

Скрипт запрашивает FTP-реквизиты во время выполнения. Пароли не должны
храниться в репозитории.

## Что Git не переносит

Следующие данные намеренно исключены из репозитория:

- `_backups/` — локальный архив Tilda;
- `_drive_latest_cars/` — временно импортированные фотографии;
- `_publish-homepl/` — генерируемая папка публикации;
- `tmp/` — временные файлы;
- `node_modules/` — восстанавливается командой `npm install`;
- ZIP-архивы и исходные PDF/документы;
- `.codex/` и `.agents/` — локальное состояние инструментов;
- пароли, ключи, `.env` и FTP-реквизиты.

Если архив Tilda, исходные документы или импортированные фотографии ещё
нужны, перенесите их отдельно через защищённый накопитель или облачное
хранилище. Пароли лучше заново получить из менеджера паролей, а не копировать
в папку проекта.

## Проверка перед отключением старого компьютера

В папке Atlant Auto выполните:

```powershell
git status --short --branch
git push origin main
```

Перед окончательным переходом проверьте:

- нужные изменения закоммичены и отправлены в GitHub;
- `git status` не показывает важных незакоммиченных файлов;
- локальные архивы, документы и фотографии либо скопированы отдельно, либо
  подтверждены как ненужные;
- на новом компьютере репозиторий клонируется и открывается;
- `npm test` проходит;
- известны доступы к GitHub, home.pl, домену, Google Search Console, Analytics
  и другим используемым внешним сервисам.

Не удаляйте данные со старого компьютера, пока эти проверки не завершены.
