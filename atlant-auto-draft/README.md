# Atlant Auto Draft

Черновик нового сайта вне Tilda. Рабочая версия на Tilda может оставаться опубликованной, пока этот вариант дорабатывается.

## Как открыть

Откройте `index.html` в браузере.

## Как добавлять авто через Codex

Автомобили сейчас хранятся в массиве `cars` в `app.js`. Для новой машины нужно добавить объект с полями:

- `id`
- `status`
- `title`
- `image`
- `price`
- `mileage`
- `date`
- `engine`
- `summary`
- `highlights`

Позже это можно вынести в `cars.json`, Google Sheets или небольшую админку.
