# Atlant Auto · Arval Capture 0.4.11

Расширение Chrome для английского интерфейса Arval MotorTrade: серверные черновики и посты для Telegram.

## Установка

1. Откройте chrome://extensions и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите эту папку с manifest.json.
3. Откройте лот Arval под своим аккаунтом, вручную раскройте Links and documents и нужные разделы.
4. Нажмите значок расширения. В «Подключение сотрудника» вставьте свой access_key и нажмите «Сохранить и проверить подключение».

При обновлении замените файлы расширения, нажмите кнопку перезагрузки в chrome://extensions, закройте старую вкладку расширения и откройте заново из Arval.

## Основные действия

Три кнопки находятся рядом:

- «Сохранить на сервере» — сразу сохранить данные, все найденные обычные фото и фото повреждений, приложенные PDF. Результат и ссылка на черновик появляются рядом с кнопками. Повторное сохранение обновляет тот же VIN, сохраняя историю.
- «Пост для Telegram» — открыть предпросмотр текста и выбор фотографий. Отправка выполняется отдельной кнопкой внутри предпросмотра.
- «Перечитать лот» — вспомогательное действие: повторно прочитать открытую карточку Arval и ранее сохранённые данные PartsLink по VIN. После успешного чтения PDF нажимать не требуется.

PDF можно выбрать заранее в свёрнутом блоке «Прикрепить PDF перед сохранением · необязательно». PDF PartsLink для чтения даты/характеристик импортируется в отдельном блоке «Данные PartsLink». Ссылки на отчёты сохраняются во внутренних данных; оригинальные PDF отчётов нужно приложить файлом.

Локальный пакет и автоматическое сохранение файлов в «Загрузки» удалены. Разрешения downloads и доступа к Macadam больше не запрашиваются. Ссылки на инспекции и их выдача через бота сохранены. Права расширения: activeTab, scripting, storage и опциональный доступ к техническому серверу home.pl. Пароль Arval и токен бота сотруднику не передаются.

Оставьте вкладку расширения открытой до завершения серверной загрузки. Частично сохранённый черновик явно помечается, ошибки отображаются в журнале. Расширение не нажимает торговые кнопки и не отправляет ставки.

## История реализации

Ниже сохранены заметки о предыдущих версиях. Упоминания локального пакета, папки Загрузки, capture-manifest.json и локальной копии Macadam относятся к старым выпускам; с 0.4.8 этого режима нет. Текущее поведение основных кнопок описано выше.

## Границы первой версии

- Адаптер проверен по разметке одного BMW X2; для других языков/типов аукционов понадобится проверка.
- Цена распознаётся только при явной подписи Highest Bid. Налоговый режим ставки не выводится из VAT Deductible.
- Таймер сохраняется исходным текстом со временем сбора; абсолютная дата окончания остаётся null.
- Сервисная история сохраняется исходным текстом, без выдуманных записей.
- Повторный сбор создаёт новую папку снимка. При сохранении на сервере один VIN обновляет тот же черновик; прежние снимки сохраняются, файлы дедуплицируются по SHA-256.
- Нет публикации в публичный каталог, Drive или AI. Закрытое серверное хранилище и Telegram подключены; на компьютере сотрудника нужно установить расширение и ввести отдельный ключ.
- Ссылки на PDF, выданные только через JavaScript/отдельные домены, требуют дополнительного адаптера.
- Вкладку сохранения нельзя закрывать до завершения.

## Проверка версии

Разметка сверена с открытым лотом BMW X2 17 октября 2026: 12 основных фото, 14 фото повреждений, 14 опций, 6 замечаний. Проверены поля и ссылки отчёта Macadam. Автоматические проверки `tools/arval-capture.test.cjs` покрывают разбор DOM, дедупликацию фото, тип цены, пропуски, ошибки скачивания, отчёт с несовпадающим VIN, экранирование текста и конфликт данных источников. Эти проверки используют тестовые ответы Chrome; фактическое скачивание из авторизованной сессии требует первого запуска установленного расширения.

Разрешения: activeTab (открытый пользователем лот), scripting (чтение DOM и получение фото), downloads (сохранение пакета), storage (комплектация по VIN и отдельный ключ сотрудника). Доступ ко всем сайтам, cookies, debugger и пароли не запрашиваются. Опциональный доступ к www4.macadam.eu нужен для отчёта; к техническому домену home.pl — для отправки Telegram-черновика.

## Telegram и partslink24 (0.2)

Для BMW в partslink24 откройте страницу идентификации по VIN, вручную раскройте «Данные автомобиля», «Серийная комплектация» и «Спецоборудование», дождитесь загрузки и нажмите расширение. Оно читает открытые разделы и сохраняет данные локально в Chrome. При закрытых разделах сообщает, что нужно открыть их вручную. После этого откройте тот же VIN в Arval и нажмите расширение: сохранённая комплектация присоединяется по VIN с датой и источником. Повторный сбор partslink24 обновляет локальную копию. Другие марки и автоматический переход Arval → partslink24 ещё не подключены.

Кнопка «Пост для Telegram» открывает редактируемый текст и выбор 2–10 обычных фотографий. Текущая ставка не называется начальной ценой. Неизвестные значения не заполняются. Из комплектации берутся проверенные сопоставления названий/кодов опций; необычные коды остаются в исходных данных. Ссылка на инспекцию включается отдельно. partslink24 не заменяет инспекцию фактического состояния.

Шаблон фото (0.2.3): пять кадров — передний левый, задний левый, задний правый, передний правый и общий вид салона; первый — обложка. Для исходного BMW X2 эти ракурсы визуально сверены с галереей Arval и соответствуют файлам 01–05. По умолчанию отмечаются первые пять обычных фото, без снимков повреждений. Универсального распознавания ракурсов пока нет: перед отправкой другого автомобиля нужно проверить выбор, поскольку порядок фотографий может отличаться. Используются найденные оригиналы изображений без элементов интерфейса аукциона.

Серверная отправка подключена 17 октября 2026: тестовый альбом из двух фото доставлен в настроенную закрытую группу; повтор не создал дубликат. В расширении хранится отдельный ключ сотрудника, а токен бота и фиксированный chat_id остаются на сервере. На home.pl они размещены в закрытом HTTP-каталоге внутри файловой изоляции PHP; прямой доступ возвращает 403. Разрешения storage и опциональный доступ к техническому домену home.pl нужны для этой функции.

При нажатии «Отправить черновик боту» выбранные фото читаются через открытую авторизованную вкладку Arval и передаются серверу вместе с подписью. Сервер отправляет альбом в один настроенный закрытый чат. Обрабатываются неподтверждённые попытки без автоматической повторной отправки. Публикацию в канал делает коллега вручную после проверки.

Для коллеги: установите 0.4.0, нажмите «Пост для Telegram», в блоке серверного сохранения раскройте «Подключение сотрудника» и введите выданный отдельно ключ. Токен бота вводить не нужно. Ключ не входит в ZIP. Идентификатор распакованного расширения должен быть `ajdaabpilohkabccbejmbemffbmniikc`: он закреплён открытым ключом в manifest.json. Этот ID разрешён сервером. При установке поверх старой версии с другим ID загрузите папку 0.4.0 как новое распакованное расширение.

Запуск из установленного расширения в аккаунте сотрудника ещё нужно проверить. Проверка серверной доставки выполнена с реальными фото, полученными из карточки Arval. Автономный сбор лотов и partslink24 на сервере пока не развёрнут.

## Защита от действий на аукционе (0.2.2)

Убраны автоматическое открытие документов Arval и раскрытие панелей partslink24. Код, исполняемый в этих вкладках, читает DOM; получение фото делает явный GET только по проверенному адресу изображения того же VIN. Автоматических кликов, ввода, отправки форм и торговых запросов в коде нет. Расширение не содержит модели с управлением браузером. Отдельный тест запускает реальный сценарий чтения против тестовой страницы с ловушками на click/submit/requestSubmit и фиксирует ноль управляющих действий и ноль запросов записи.

Это ограничение нашей реализации, а не отдельная роль read-only, предоставленная Chrome. Разрешение scripting технически позволяет исполнять код в активной вкладке. Проверка кода/версий остаётся обязательной; файл manifest.key закрепляет ID, но не является проверкой доверенности или подписью ZIP. Полномочия торгового аккаунта пользователя не меняются. Для серверного автономного сбора предпочтительны отдельный аккаунт без права торговли (если площадка поддерживает), ограничения сетевых операций и изоляция сборщика от генератора текста. Для каждого следующего аукциона требуется отдельная проверка адаптера.

Не копируйте пакеты автомобилей в Git. Экспорт — внутренний источник; публикацию фотографий и документов следует выбирать отдельно в будущей админке.


## Серверные черновики · 0.3.0

Кнопка **«Сохранить черновик на сервере»** передаёт исходные данные и все найденные фото Arval, включая повреждения, на HTTPS API home.pl. Для каждой загрузки отображается результат; ошибки оставляют частичный черновик и могут быть повторены без дублей. Можно приложить один или несколько PDF до 20 МБ каждый — инспекцию или выгрузку PartsLink. VIN внутри PDF ещё не распознаётся: проверьте соответствие вручную. Ссылка на HTML-инспекцию сохраняется, но сама страница Macadam этим действием не архивируется на сервер. При необходимости приложите её PDF вручную.

Ключ сотрудника настраивается под блоком серверного сохранения. Перед отправкой альбома в Telegram сохраняются данные и только выбранные для альбома фото; полную галерею сохраняйте отдельной кнопкой. Успешное сохранение не публикует автомобиль и не отправляет сообщений. История содержит текст, попытку и подтверждение отправки Telegram; при сбое записи истории доставка может пройти, а событие отсутствовать — ответ API содержит history_saved.

Закрытый просмотр: https://serwer2454127.home.pl/drafts/ — тот же логин/пароль просмотра, что для презентации. Поиск по VIN, модели и номеру лота; скачивание файлов, JSON и прежних снимков. Сотрудники с действующим ключом API в этой версии имеют доступ ко всем черновикам; разделения по владельцам пока нет. Ключ не даёт доступа SSH и не позволяет нажимать торговые кнопки.

Обновление: распакуйте ZIP 0.4.0 в постоянную папку, выберите её через «Загрузить распакованное расширение» в chrome://extensions либо замените файлы установленной папки и нажмите «Обновить». ID и ключ сотрудника сохраняются при обновлении той же установки. Не включайте режим «Разрешить доступ ко всем сайтам».

## Кнопки под постом · 0.4.0

Под альбомом бот отправляет отдельное сообщение с URL-кнопками «Запросить фото повреждений», «Инспекция» и «Данные PartsLink». Каждая ведёт в личный чат бота с непрозрачным ID объявления; при первом обращении Telegram может потребовать «Старт». Сам альбом не поддерживает reply_markup. При ручной публикации нужны оба сообщения; сохранение кнопок конкретным способом пересылки нужно проверять, для гарантированного оформления требуется публикация ботом в подключённый канал (ещё не подключён).

Запрос фото сохраняет VIN/черновик, Telegram ID, имя и username заявителя, время и статус. Один человек не создаёт повторные обращения по тому же VIN в течение суток. Группа менеджеров пока не создана: запрос остаётся в очереди на сервере, бот не сообщает о доставке менеджеру. Его видно внутри закрытого черновика в «Запросах фото повреждений».

Для PDF выберите назначение перед сохранением: внутренний документ, инспекция или PartsLink. Одинаковый PDF при повторной загрузке можно переклассифицировать. Перед отправкой поста отдельными флажками разрешается выдача инспекции/PartsLink. Снимок для конкретного поста включает только разрешённые PDF и комплектацию; внутренние файлы, остальные фото и полный приватный JSON в бот не выдаются. Ссылки доступны любому читателю поста — проверьте документы перед разрешением. Назначение PDF не проверяет автоматически его содержимое/VIN.

Инспекция — до трёх помеченных PDF и/или разрешённая ссылка Macadam; исходная ссылка может требовать авторизации. PartsLink — до трёх помеченных PDF и сохранённые коды/названия опций отдельным TXT. Автоматического входа в PartsLink нет. При отсутствии данных бот прямо сообщает, что материалы пока не приложены.

Альбом и карточка кнопок имеют раздельные статусы доставки. При неопределённом результате автоматического повтора нет. После обновления файлов в установленной папке нажмите «Обновить» на карточке расширения в chrome://extensions/; новых разрешений в 0.4.0 нет.

## Сервисная история · 0.4.1

Раздел Maintenance history читается без нажатий: отдельные строки таблицы/div-разметки сохраняются как date_source, date_month (месяц без выдуманного дня), mileage_km, description_source. Исходный текст и заявленное Arval число записей сохраняются отдельно. При несовпадении количества строк появляется предупреждение; неизвестная история не превращается в ноль, ноль записей не означает отсутствия обслуживания. Описания работ не переводятся автоматически и не дополняются предположениями о замене масла.

В предпросмотре есть флажок «Добавить краткую сервисную историю в пост и разрешить выдачу полной истории через кнопку». Краткая строка показывает количество прочитанных записей; последняя датированная запись указывается только при отсутствии расхождения с заявленным числом. Четвёртая кнопка «Сервисная история» ведёт в личный чат бота. Короткая история приходит текстом, длинная — TXT. Получатель сообщения — только соответствующий пользователь, не группа. Временные персональные ответы внутри группы Telegram поддерживает, но в этой версии не подключены.

Для существующей страницы сначала обновите расширение в Chrome, вручную раскройте сервисный раздел, затем «Перечитать лот» и проверьте число записей. Старые посты/снимки автоматически не дополняются; четвёртая кнопка и разрешённая история появятся в новом посте. Исходный HTML реального нового лота ещё нужно проверить установленным расширением; автоматические тесты используют пять строк по примеру скриншота и table/div-разметку. Данные со скриншота не привязывались к демонстрационному VIN.

## Подключение сотрудника · исправление 0.4.2

В предыдущих версиях подтверждение сохранения ключа выводилось в скрытый Telegram-блок, поэтому кнопка выглядела неработающей. Теперь кнопка «Сохранить и проверить подключение» показывает результат прямо под полем ключа. Она проверяет формат, записывает ключ в Chrome storage, перечитывает его для подтверждения и выполняет безопасный GET action=identity на нашем сервере. Ответ содержит только имя сотрудника, не список автомобилей. При успехе видно «Подключено: owner. Ключ сохранён на этом компьютере».

Можно вставить само значение access_key, строку в кавычках или содержимое своего JSON-файла целиком: извлекается только access_key. Название owner, пароль сайта и токен бота не подходят. Отказ в разрешении доступа к серверу не отменяет локальное сохранение, но явно помечает подключение как непроверенное. Отклонённый сервером ключ и недоступное хранилище показываются рядом с полем. Если вкладка осталась от перезагруженной версии расширения, нужно закрыть её и заново открыть расширение из Arval. Переход к Telegram больше не перезаписывает введённый, но ещё не сохранённый ключ.

Проверки: видимость подтверждения при закрытом Telegram-блоке, сохранность после перезагрузки страницы, вставка полного JSON, ошибка при owner вместо ключа, отказ сервера, отказ Chrome в разрешении и потеря контекста расширения. Секрет не появляется в сообщениях статуса.

## Название для объявления · 0.4.3

Исходное vehicle.title не изменяется. Отдельно сохраняются vehicle.display_title и title_details (исходные обозначения мощности, КПП, экостандарта и комплектации). Пример: Kia Sportage Design Hybrid 1.6 T-GDi 230CV BVA6 E6d → Kia Sportage 1.6 T-GDi Hybrid. Design убирается именно у Kia Sportage как известная комплектация; неизвестные слова у других моделей автоматически не удаляются.

Первая версия — локальные проверяемые правила, не подключение к полной каталожной базе и не машинное обучение. Для Kia Sportage поддержаны обычный Hybrid, Plug-in Hybrid/PHEV и Mild Hybrid/MHEV, обозначение двигателя и объём из исходной строки. Для остальных моделей удаляются только явные суффиксы мощности CV/CH/HP/PS, французской КПП BVA/BVM с числом передач и экостандарта E6d/Euro 6; незнакомые обозначения остаются для проверки. Отдельный индекс модели e6 не удаляется. AMG, GTI, xDrive и прочие значимые индексы не вырезаются общим списком стоп-слов. Привод, двигатель, мощность и опции не достраиваются из типовой комплектации.

Поле «Название для объявления» позволяет вручную исправить результат до сохранения/отправки. ## Дата выпуска, гибрид и PDF PartsLink · 0.4.4

В строке характеристик публикуется дата производства, а не первая регистрация. Распознанная дата из PartsLink имеет приоритет над Year of production Arval; модельный год и первая регистрация не подставляются. Точность источника сохраняется: год, месяц или день. В превью видно источник. Противоречащие друг другу даты страницы/PDF требуют проверки. Исходные поля остаются в пакете вместе с publication_facts.

Два способа подключения PartsLink: открыть страницу и нажать расширение (после этого «Перечитать лот» в Arval), либо в новом блоке «Данные PartsLink» выбрать PDF и нажать «Прочитать PDF PartsLink». Старое поле PDF в разделе сервера только прикрепляет документ и не извлекает дату. Импортированный новым способом PDF сохраняется в локальный пакет и загружается на сервер с пометкой partslink. При перечитывании того же VIN в текущей вкладке он сохраняется; при новом VIN сбрасывается. При новом запуске расширения PDF нужно импортировать снова. Неудачный новый импорт не заменяет предыдущий успешно импортированный файл.

PDF разбирается локальным PDF.js 5.6.205 (Apache-2.0, файлы и лицензия в vendor/pdfjs), без загрузки кода с CDN. JavaScript/XFA PDF не выполняются; сохраняются только текстовые поля. Ограничения: 20 МБ, 30 страниц, 500000 символов, 30 секунд. Требуется обозначение PartsLink24 в тексте и ровно один полный совпадающий VIN. VIN из имени файла не используется. Сканы без текста и страницы с неподдержанными подписями требуют открытой страницы PartsLink; OCR и распознавание всех вариантов каталожной разметки не подключены. Выделяются явные подписи даты производства и типа двигателя/топлива на русском, английском и немецком. Комплектация из PDF остаётся оригинальным PDF/текстом; коды опций автоматически из PDF не реконструируются. Реальный PDF пользователя ещё требуется для проверки конкретного шаблона.

MHEV/Mild Hybrid обозначается как «мягкий гибрид (бензин/дизель)» только при наличии соответствующих исходных обозначений. T-GDi/GDi и CRDi учитываются как бензиновое/дизельное обозначение двигателя. Слово Hybrid само по себе не превращается в MHEV. HEV/FHEV/Full Hybrid и PHEV/Plug-in отличаем отдельно. Противоречащие подписи требуют проверки. Это правило публикации компании, не заключение о допустимости экспорта. В текущем интерфейсе подготовка поста доступна, но кнопка отправки отключается для полного/подзаряжаемого/неуточнённого гибрида, гибрида без установленного топлива и при неподтверждённой дате выпуска. Хранение черновика не блокируется. Это проверка актуального расширения: старые версии и вручную пересланный текст она не ограничивает; публичный канал пока не подключён.

НДС к вычету и налоговая база суммы — разные факты. При явном VAT Deductible=Yes пишется «НДС к вычету», при No — «НДС к вычету не заявлен», при отсутствии данных — «НДС к вычету: уточняется». Подпись «НДС в цене» не используется для ставки нетто. Сумма не увеличивается автоматически на ставку НДС; неизвестная база суммы помечается «нетто/брутто уточняется». Метод расчёта продажной цены пока не менялся.

Проверки: фактическое чтение байтов тестового PDF локальным PDF.js worker, несовпадающий/множественный VIN, даты с разной точностью и несуществующие даты, приоритет PartsLink, MHEV бензин/дизель, HEV/PHEV/неуточнённый гибрид, загрузка PDF в UI и запрет отправки HEV при сохранении возможности хранить черновик. Все сетевые вызовы этих тестов — заглушки, реальных сообщений не отправляется.

## Значимые опции для объявления · 0.4.6

Основной источник короткой строки «В комплектации» — список опций PartsLink: страница и распознанные структурированные строки PDF. Если список PartsLink есть, данные Arval к нему не подмешиваются. Если список ещё не загружен, используется явно помеченный в превью источник Arval. Наличие только базовых или нераспознанных опций в PartsLink не является поводом добрать неподтверждённые опции с аукциона.

Выбор ограничен пятью наиболее приоритетными подтверждёнными опциями из разрешённого набора: камеры 360°, адаптивный круиз, панорамная крыша, матричные/адаптивные LED-фары, проекционный дисплей, вентиляция и память сидений, задняя камера, подогревы, контроль слепых зон, электробагажник и другие узнаваемые полезные опции. Сильная версия исключает дубли: камеры 360° вместо обычной камеры, адаптивный круиз вместо обычного, адаптивные LED вместо обычных LED. Усилитель руля, ABS и другие базовые позиции не включаются в краткий пост. Отрицательные формулировки (например «без панорамной крыши» или Without rear view camera) не становятся положительными признаками. Неизвестные обозначения не угадываются. Это локальные правила для явных названий на русском/английском и отдельных названий на немецком/французском, не универсальный перевод каталога. Предыдущие BMW-коды ограничены маркой BMW; новые коды других производителей не интерпретируются по этому словарю.

В превью «Главное в комплектации» видно выбранные опции и источник. В пакете vehicle.equipment_highlights сохраняет выбранные пункты вместе с исходной подписью, кодом и источником. Полная исходная комплектация не урезается и остаётся доступна через кнопку PartsLink. Структурированные PDF-строки распознаются только в разделах Standard equipment / Optional equipment и их известных русских/немецких аналогах: код и подпись в одной строке либо код в отдельной строке перед подписью. Скан, свободное описание и неизвестный шаблон PDF не преобразуются в выдуманные опции; реальный формат PDF пользователя ещё требует проверки. Старые посты автоматически не меняются.

## Реальный PDF PartsLink с PR-таблицей VAG · 0.4.9

Импорт проверен на предоставленном пользователем семистраничном PDF. У этого формата логотип PartsLink является изображением и отсутствует в извлечённом тексте. Вместо требования текстового логотипа допускается точная структура «Идентификация автомобиля» / «Номер шасси» / «Дата производства» / «Номер PR» с обязательным единственным совпадающим полным VIN. Это распознавание шаблона, не проверка подлинности документа.

PDF.js объединяет элементы по координатам строки, независимо от hasEOL у отдельных ячеек, сортирует строки и сохраняет структуру колонок. Адаптер PR-таблицы читает отдельную колонку кода, подпись справа и её переносы между строками/страницами. Заголовки таблицы и номера страниц не включаются в подписи. Поддержаны буквенные коды пакетов, а не только буквенно-цифровые. Технические исходные поля модели, модельного года и кодов двигателя/КПП сохраняются отдельно от даты производства. Явная строка «Базовый двигатель» служит источником типа двигателя; запись «Без электродвигателя (гибрид)» не превращается в положительный признак гибрида.

Расширен выбор значимых опций по явным подписям реального формата: Area View, полный привод, электросиденье с памятью, обогреваемое рулевое колесо и светодиодная основная фара. Если электрорегулировка с памятью подтверждена только для одного сиденья, не утверждается наличие двух электросидений. Отрицательные позиции, включая отсутствие HUD, исключаются. В интерфейсе показывается количество распознанных позиций PDF; при PDF без захвата открытой страницы предпросмотр Telegram больше не утверждает, что PartsLink отсутствует.

Регрессионный тест использует обезличенный макет колонок и переносов, без исходного файла пользователя. Реальный файл отдельно проверен локально через тот же PDF.js и readPartslinkPdf: 205 уникальных PR-кодов. PDF не включается в архив расширения и не отправлялся в Telegram в ходе проверки. Поддержка иных шаблонов PDF по-прежнему требует проверки.

## Первая регистрация при отсутствующей дате PartsLink · 0.4.10

После успешного чтения страницы или PDF PartsLink проверяется наличие даты производства в конкретной выгрузке. При достоверной дате она остаётся приоритетной. Если поле отсутствует, пустое или содержит явную заглушку (например — / N/A / не указана), для строки объявления используется первая регистрация Arval с явной подписью: «04.2023 · первая регистрация». Правило определяется данными выгрузки, без предположения об отсутствии даты у всей марки; оно подходит в том числе для описанного пользователем случая Stellantis.

Производство и регистрация не смешиваются: publication_facts.production остаётся null при отсутствующей дате производства, first_registration содержит нормализованное значение Arval, display_date содержит выбранную дату и kind=first_registration/production. Также сохраняются исходное значение и источник. Модельный год не подставляется. В интерфейсе добавлена строка «Дата в объявлении» и пояснение о запасном источнике. Отправка при распознанной первой регистрации разрешена с сохранением остальных проверок, включая тип гибрида.

Нераспознанная непустая либо противоречивая дата PartsLink по-прежнему блокирует отправку для проверки. При отсутствии пригодной первой регистрации публикация также требует проверки. До чтения PartsLink отсутствие даты в нём не объявляется установленным: прежний явно указанный Year of production Arval может использоваться, но автоматический переход к регистрации требует загруженного PartsLink. Даты Arval вида Apr-23 нормализуются с сохранением точности месяца; день не выдумывается. В чтении PDF пустая дата перед следующим распознаваемым полем не поглощает его значение.

Проверены: отсутствующее и пустое поле, заглушка, каталог из страницы/PDF, приоритет реальной даты производства, ошибочная/противоречивая дата, нераспознанная регистрация и полный сценарий импорта PDF без даты с первой регистрацией в превью Telegram. Пример реальной выгрузки Stellantis без даты ещё нужен для проверки именно её PDF-разметки; это обновление не объявляет универсальную поддержку всех шаблонов PDF.

## Последовательность действий и PDF Opel/Stellantis · 0.4.11

Порядок основных кнопок: «Сохранить на сервере» → «Пост для Telegram» → «Перечитать лот». В интерфейсе добавлена последовательность: выбрать PDF PartsLink → прочитать PDF и дождаться зелёного подтверждения → сохранить на сервере → открыть предпросмотр поста → проверить текст/фото и отправить черновик боту. «Перечитать лот» — вспомогательное чтение Arval, после успешного импорта PDF нажимать его не требуется.

Данные PDF присоединяются к пакету в текущей вкладке сразу после успешного «Прочитать PDF PartsLink», ещё до сохранения на сервере. Серверное сохранение сохраняет этот пакет и файл, а пост формируется из тех же данных в текущей вкладке. Кнопка «Пост для Telegram» сама сообщение не отправляет. Отдельное предварительное серверное сохранение рекомендуется для архива всех фото; фактическая отправка Telegram по-прежнему автоматически сохраняет актуальные данные, выбранные фото и PDF перед отправкой. После закрытия вкладки импорт PDF в новой вкладке нужно повторить; восстановление PDF из серверного черновика этим обновлением не добавляется.

Выбор файла без чтения больше нельзя незаметно проигнорировать. Новый выбранный, но ещё не прочитанный PDF, а также отклонённый импорт блокируют переход к посту, отправку/копирование и обычное серверное сохранение с понятной инструкцией. Предыдущий успешно прочитанный файл не маскирует ошибку нового. Для хранения неподдержанного файла только как документа нужно убрать его из поля импорта и приложить в общий PDF-раздел.

Добавлен формат Stellantis: «Идентификация автомобиля», двухколоночные «Данные автомобиля» и «Оснащение», без PR-кодов и без обязательной даты производства. Адаптер сохраняет полные исходные подписи/значения и переносы, проверяет единственный совпадающий VIN, читает двигатель и оборудование без интерпретации DAM или окна изменений как даты производства. Проверен локально на пользовательском восьмистраничном PDF Opel: 260 строк оснащения. Дата отсутствует, работает явный fallback первой регистрации Arval. Важные опции из этого шаблона распознаются по паре «категория + значение»; отрицательные позиции не становятся положительными, например отсутствие панорамного обзора не превращается в камеры 360°.

Проверены оба реальных шаблона (VAG и Stellantis), существующие сценарии импорта, сохранения/Telegram и запрет игнорирования непрочитанного PDF. Исходный пользовательский PDF не включается в архив и во время проверки не отправлялся в Telegram.

Выбор хранится в пакете vehicle.equipment_selection, сохраняется на сервере вместе с черновиком и сохраняется при перечитывании того же VIN в открытой вкладке; смена VIN не переносит выбор. Галочки пересобирают текст, поэтому ручные изменения текста делайте после выбора. Полная комплектация PartsLink по кнопке не сокращается до выбранного рекламного списка. Длинная подпись не обрезается: лимит альбома — 1024 знака вместе с серверным оформлением и временем, при превышении сократите описание/список.
